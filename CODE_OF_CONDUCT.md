# Code of conduct

Keel is built by people with different backgrounds, languages and levels of experience. Respect is a
requirement for taking part, not a suggestion.

## Expected

- Assume good intent; critique code and ideas, never people.
- Be patient with newcomers; explain the why.
- Accept decisions made through the RFC process, and use the process to change them.

## Not acceptable

Harassment, insults, discriminatory language or imagery, personal attacks, sustained disruption, publishing
others' private information, and unwelcome sexual attention, in any project space (issues, pull requests,
chat, events) or in private messages about the project.

## Enforcement

Report incidents privately to the core maintainers (contact details are listed in the repository's
`MAINTAINERS` file once the core team is formed; until then, contact the project author). Reports are handled confidentially by at least two core maintainers
not involved in the incident. Responses range from a private warning to a permanent ban, and are recorded.
Maintainers are held to this code more strictly, not less.
